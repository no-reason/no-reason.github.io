# Yiyan Zhang's Academic Homepage

Personal academic website for Yiyan Zhang, an undergraduate student in Information and Computational Science at Dalian University of Technology.

The site is built with Jekyll and the [AcademicPages](https://github.com/academicpages/academicpages.github.io) template, with a custom responsive visual layer and automatic GitHub Pages deployment.

## Local development

```bash
bundle install
bundle exec jekyll serve --config _config.yml,_config_docker.yml
```
